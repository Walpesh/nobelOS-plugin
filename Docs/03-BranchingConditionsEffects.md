# Ветвления, условия, эффекты

## Выбор

У Choice Node каждый вариант содержит:
- `Label` — текст кнопки;
- `Next Node` — куда ведёт;
- `Show Conditions` — **если не выполнены, вариант скрыт полностью**;
- `Enable Conditions` — **если не выполнены, вариант виден, но серым**;
- `Effects` — что происходит при клике.

## Condition Builder

В инспекторе Choice Node у каждого варианта есть кнопки:
`+ Show if condition`, `+ Enable if condition`, `+ Effect`.
Ассет условия/эффекта создаётся сам (папка `Conditions/` рядом с узлом)
и сразу открывается вложенным инспектором для настройки параметров.

## Виды условий

| Условие | Проверяет |
|---|---|
| Attribute | число/bool/строку атрибута: `==, !=, >, >=, <, <=` |
| Flag | булев флаг (`expected = true/false`) |
| Node Visited | был ли игрок в узле с таким id |
| Choice Made | выбирал ли игрок вариант с таким id |
| Scene Context | локация / время суток / настроение текущей сцены |
| Group (All/Any) | композиция условий: «все» или «любое» |

## Виды эффектов

| Эффект | Действие |
|---|---|
| Modify Attribute | прибавить/записать число (деньги −10, репутация +1) |
| Set Flag | установить флаг |
| Set String Attribute | записать строковое значение |
| Raise Story Event | послать именованное событие (катсцены, звук вне UI) |

## Долгосрочные последствия

Ранний выбор влияет на поздние главы через **Choice Made** и **Node Visited**:
ставь их в `Show/Enable Conditions` выборов и финалов следующих глав.
Веди таблицу «id выбора → что открывает», чтобы не потерять нити.

## Переход между главами

Ссылки `Next Node` не должны уходить в другой граф (иначе сломается загрузка сейвов).
Используй узел-переход (расширение движка, код есть в [08-ForProgrammers](08-ForProgrammers.md#graph-jump)):
последний узел главы = `Graph Jump` на `Entry Node` следующей главы.

## Балансировка порогов

- Держи таблицу изменений атрибутов по выборам.
- В Play Mode живые значения видны: **StoryEngine → Attribute Manager** (колонка `live`).
- Для быстрых проверок порогов используй чит-компонент из [09-Troubleshooting](09-Troubleshooting.md#читы-для-тестов).
