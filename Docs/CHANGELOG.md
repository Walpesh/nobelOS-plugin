# Changelog

## 1.0.0
- Core: узлы Line/Choice/End, спикеры, нарратор, ключи локализации, Dialogue Runner, события.
- Условия и эффекты: атрибуты (Number/Bool/String), флаги, история выборов, контекст сцены, группы All/Any.
- Фоны: каталог, crossfade, оверлей, параллакс; контекст сцены на узлах.
- Финалы: End Nodes, Ending Definitions, секретные финалы, мета-профиль, статистика выборов.
- Сохранения: 3 слота JSON + автосейв-сниппеты, восстановление атрибутов и истории.
- Editor Tools: GraphView-редактор, Attribute Manager, Condition Builder, Ending Editor, Preview Mode, валидатор (unreachable/cycles).
- UI: диалоговое окно, typewriter без аллокаций, пул кнопок с disabled-состоянием, экран финала со статистикой.
- Примеры: core-семпл и full-семпл (атрибуты, условия, эффекты, 5 финалов, CSV).
