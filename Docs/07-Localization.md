# Локализация

## Модель

Каждый текст = `Key` + `Fallback`.
Если назначен провайдер локализации и ключ найден — показывается перевод, иначе `Fallback`.

## CSV-формат

```csv
key;value
ch01_l010;Дождь. Перекрёсток.
ch01_c010_o1;Купить карту (10 монет)
```

- разделитель: `;` (или `,` / таб);
- первая строка-заголовок `key;value` игнорируется;
- `\n` внутри value = перенос строки в реплике;
- один файл = один язык; на каждый файл создай ассет **Localization CSV**.

## Процесс

1. Пиши узлы с `Fallback` на исходном языке и ключами по соглашению (`ch01_l010`, `ch01_c010_o1`).
2. Переводчик получает только CSV — без доступа к Unity.
3. Правило синхронизации: новый узел = новая строка CSV в том же коммите.
4. Переключение языка — `runner.SetLocalizationProvider(...)` (меню/настройки).

## Имена спикеров

`Display Name` спикера не локализуется ключами по умолчанию;
для мультиязычных имён держи отдельных Speaker-ассетов на язык или расширяй провайдер.
