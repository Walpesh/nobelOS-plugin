# Story Engine 2D

**Data-driven движок историй для Unity: визуальные новеллы и choice-driven игры без программирования.**

Купил плагин → развернул игру → собрал билд. Код не нужен.

![Unity](https://img.shields.io/badge/Unity-2021.3%2B-black) ![License](https://img.shields.io/badge/license-MIT-green) ![Version](https://img.shields.io/badge/version-1.0.0-blue)

> 📖 Начни здесь: [Docs/01-QuickStart.md](Docs/01-QuickStart.md) — играбельная новелла за 10 минут.

## Что это

Story Engine 2D — шаблон-фреймворк для 2D story-игр. Всё содержание истории
(диалоги, выборы, условия, атрибуты, фоны, финалы) живёт в **ScriptableObject-ассетах**,
а не в коде. Автор работает в Inspector и визуальном редакторе графа.

## Возможности

- 💬 Узлы диалогов: реплики, спикеры, нарратор, портреты, озвучка (опционально)
- 🔀 Ветвление без ограничений по глубине; визуальный **GraphView-редактор графа**
- 🧠 Условия и эффекты выборов: атрибуты (число/bool/строка), флаги, история выборов, контекст сцены
- 🙈 Скрытые и заблокированные варианты ответов («нужна репутация ≥ 3»)
- 🖼 Фоны с плавной сменой, оверлеем и параллаксом; контекст сцены (локация/время/настроение)
- 🏁 Несколько финалов + определения финалов с условиями + секретные финалы
- 💾 Save/Load: 3 слота + автосейв, JSON; мета-профиль: открытые финалы и статистика выборов
- 🌍 Локализация через ключи + CSV-провайдер
- 🛠 Editor Tools: граф-редактор, Attribute Manager, Condition Builder, Ending Editor, Preview Mode, валидатор (недоступные узлы, циклы)
- 🎨 UI-слой отделён от логики: меняй визуальный стиль, не трогая историю
- 📱 Mobile-friendly: без LINQ в runtime, пулы кнопок, typewriter без аллокаций

## Требования

- Unity **2021.3 LTS / 2022.3 LTS / 6000.x**
- Пакеты: uGUI, TextMeshPro (в 2D-шаблонах уже есть)

## Установка (30 секунд)

**Способ 1 — папкой:** скопируй содержимое репозитория в `Assets/Plugins/StoryEngine/` своего проекта.
**Способ 2 — UPM:** Package Manager → *Add package from disk…* → `package.json`.

Готово: в меню Unity появится пункт **StoryEngine**.

## Быстрый старт (5 минут)

1. Меню **StoryEngine → Create Full Sample Story (All Systems)** — сгенерируется пример:
   атрибуты, условия, эффекты, фоны, 5 финалов, CSV-локализация.
2. Создай пустую сцену, добавь GameObject с компонентом `DialogueRunner`,
   перетащи в поле **Story Project** ассет `Project_FullSample`.
3. Добавь туда же `Debug Dialogue Presenter` и `Debug Dialogue Input`.
4. **Play.** `Space`/клик — дальше, `1…5` — выборы. Часть вариантов скрыта/серая — это условия.
5. Меню **StoryEngine → Dialogue Graph Editor** — посмотри историю как граф.

Дальше: [своя первая глава](Docs/02-AuthoringBasics.md) и [полноценный UI](Docs/06-SceneAndUI.md).

## Философия

- **Zero hardcoded story** — любая история собирается только данными.
- **Контент-мейкер не трогает код** — Inspector, граф-редактор, валидаторы.
- **Build-ready** — настроил данные → нажал Build.
- **Модульность** — ненужные системы отключаются без поломки остальных.
